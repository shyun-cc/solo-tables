## 本轮文档流程

需求澄清 → 更新讨论稿 → 草稿 PR 评审 → 确认范围与决策 → 另开业务实现任务。

PR 构建只验证静态文档。发布工作流仅允许主分支版本发布；本讨论稿不因推送草稿分支而上线。
