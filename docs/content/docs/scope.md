> **设计讨论稿 · 尚未实现。** 本页的业务内容为提案或待确认，不能视为已交付功能。

## 本轮目标

- 建立可以公开评审的设计讨论入口，明确事实、提案和未知事项。
- 让文档在独立 `docs/` 目录可重复构建，并准备兼容 GitHub 项目子路径的 Pages 工作流。
- 在业务编码前确认首个问题、最小闭环、输入输出与验收方式。

## 本轮非目标

不交付业务实现、运行中的业务服务或生产数据操作；不执行交易系统，不连接外部业务账户。文档发布配置不包含业务部署配置。

## 产品范围待确认

| 项目 | 当前状态 | 讨论需要的结果 |
| --- | --- | --- |
| 服务对象 | 待确认 | 谁在什么场景使用 |
| 核心问题 | 待确认 | 现有方式的具体困难 |
| 最小功能 | 待确认 | 一条可验收的任务闭环 |
| 排除范围 | 待确认 | 首版明确不处理的需求 |
| 运行与访问方式 | 待确认 | 本地或托管、公开或受限及其理由 |

提案：先用一个不含敏感信息的示例讲清任务，再讨论功能清单。此顺序尚待评审。
