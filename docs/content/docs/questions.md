> **设计讨论稿 · 尚未实现。** 本页的业务内容为提案或待确认，不能视为已交付功能。

## 先确认这些问题

| 优先级 | 问题 | 影响 |
| --- | --- | --- |
| P0 | 这个项目要为谁解决什么具体问题？ | 产品目标与首版范围 |
| P0 | 能否提供一个可公开的合成示例，描述输入、动作和期望输出？ | 流程、概念模型与验收 |
| P0 | 首版必须完成什么，明确排除什么？ | 是否能开始实现 |
| P0 | 有哪些数据，来自哪里，谁可以使用和公开？ | 数据与集成边界 |
| P1 | 单人或多人使用？哪些操作需要确认或不同权限？ | 交互与访问控制 |
| P1 | 需要保存、导出或删除哪些结果？ | 持久化与生命周期 |
| P1 | 运行环境、规模、响应时间和可靠性要求是什么？ | 后续技术选择 |
| P1 | 谁确认范围与验收结论？ | 进入实现阶段的条件 |

## 回答方式（提案）

先在 PR 中回答 P0 问题，仅使用适合公开的信息。把确认结论更新到对应页面并留下决策记录；仍有分歧的项目保持待确认。不在公开 PR 粘贴私人原始资料或真实业务数据。
