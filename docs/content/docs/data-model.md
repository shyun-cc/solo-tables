> **设计讨论稿 · 尚未实现。** 本页的业务内容为提案或待确认，不能视为已交付功能。

## 当前事实

基线仓库没有实体定义、表结构、持久化代码或迁移文件。本轮不创建数据库，也不把概念模型当作数据库选型结论。

## 用于讨论的最小概念（提案）

| 概念 | 候选含义 | 待确认 |
| --- | --- | --- |
| 任务 | 一次希望完成的用户意图 | 是否确有任务概念、如何识别 |
| 输入 | 完成任务需要的信息 | 来源、格式、敏感性、是否留存 |
| 结果 | 使用者需要的输出 | 是否保存、能否修改或撤销 |
| 决策记录 | 对范围或方案的评审结论 | 谁确认、何时生效、如何替代 |

候选关系：一项任务可以引用输入并产生结果。关系的基数、生命周期、权限与删除规则均未确认；这不是表设计，不承诺持久化。

## 模型确认前的问题

- 什么需要唯一标识，是否存在重复或版本？
- 状态由什么事件改变，失败是否可重做？
- 数据拥有者、可见范围、保留与删除要求是什么？
- 是否可以只用合成数据说明流程？

在回答前不定义字段类型、主外键、索引或真实样本。
