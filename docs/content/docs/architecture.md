## 本轮已配置的文档边界

`docs/content/`（Markdown）与 `docs/hugo.yaml`（配置） → Hugo Extended + OINK → `docs/public/`（忽略的静态产物） → 合并后由 Pages 工作流发布。

文档站不承载业务 API、数据库、认证服务或作业执行器。主题依赖由 `docs/go.mod` 与 `docs/go.sum` 固定；无 Node.js/npm 或外置 Sass 构建步骤。

## 业务架构边界（提案，尚未实现）

业务用途未确定，暂不选前端框架、后端语言、数据库或部署平台。后续讨论可按以下责任边界展开，但不预设这些组件都需要独立部署：

| 候选责任 | 要先回答的问题 |
| --- | --- |
| 用户交互 | 谁提交任务、在哪里查看结果 |
| 规则处理 | 哪些规则必须由系统保证 |
| 数据保管 | 哪些数据需要保存、多久、谁能访问 |
| 外部集成 | 是否确有必要，失败影响与授权边界是什么 |

## 公开内容边界

只提交适合公开的项目说明、合成示例和必要构建配置。私人聊天、内部标识、秘密、凭据及用户财务信息不得进入源文件、截图、日志或构建产物。示例字段不应暗示已获得真实数据使用授权。
