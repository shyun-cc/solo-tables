## ADR-001：文档先行与独立文档目录

状态：本轮文档工作约定；业务方案尚未实现。

背景：基线仓库仅有许可证，没有足以支持业务实现的已确认要求。

选择：讨论稿位于 `docs/`；先通过草稿 PR 讨论目标、流程与边界，确认后另行实现。

影响：文档可独立演进；未确认项不会因写入讨论稿而成为需求。

## ADR-002：Hugo + PGSTY OINK + GitHub Pages

状态：本轮文档工具选择；发布尚待 PR 合并与 Pages 配置满足条件。

选择：使用 OINK Hugo Module `v1.5.1`、Hugo Extended `0.168.0`、Go `1.27.3`，与[官方 starter](https://github.com/pgsty/oink-starter)的核验基线一致。

理由：符合文档工具要求，官方基线无需 npm 或外置 Sass。通过带 `/solo-tables/` 的 baseURL 支持项目 Pages 路径。

影响：需要 Go 下载主题模块；生成文件不入 Git。未来升级需单独核验主题兼容性。官方允许的 LibSass 弃用警告保留可见。
